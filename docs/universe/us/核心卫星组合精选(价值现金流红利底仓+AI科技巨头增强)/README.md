# 美股核心-卫星组合股票池 (Core-Satellite Universe: US Edition) 架构说明书

## 1. 股票池设计背景与量化起源

美股作为全球深度最大、机构投资者占比最高、长期牛市趋势最显著的权益市场，其资产定价呈现清晰的“双轮驱动”结构：
- **纯高估值成长池的痛点**：在美联储紧缩加息周期（如 2022 年加息 500 bps）或宏观滞胀期，无现金流支撑的成长股估值面临剧烈杀估值，纳斯达克综合指数最大回撤超 35%，个股腰斩甚至回撤 70% 屡见不鲜。
- **纯价值红利池的优势与局限**：在宏观震荡与经济衰退担忧中，股息贵族（Dividend Aristocrats）与现金流巨头凭借高 ROIC、稳定股票回购与抗通胀定价权表现出极强韧性；但进入由通用人工智能（GenAI）、半导体硬件革命驱动的超级科技周期时，纯价值池容易错失主升浪巨额超额收益（大幅跑输标普 500）。
- **核心-卫星 (Core-Satellite) 终极解决方案**：
  * **核心底仓 (70% 风险预算，16只)**：配置跨越经济周期、拥有顶级自由现金流生成能力与持续增息/千亿回购传统的各行业垄断蓝筹（金融、能源、必选消费、工业物流、医疗与稳健科技）。作为坚不可摧的“现金流母体”，压制整体波动与最大回撤。
  * **卫星增强 (30% 风险预算，6只)**：重仓引领第四次工业革命的全球 AI 基础设施、加速计算芯片、云计算飞轮与颠覆性创新超级龙头。捕获大级别中枢突破与戴维斯双击的爆发性 Alpha。

## 3. 坚决排除的失血黑名单 (Blacklist)

在美股宽幅震荡与高利率常态下，以下标的若被纳入量化组合，极易造成持续失血与资产永久性减值：
1. **烧钱未盈利的 SPAC 壳公司与缺乏造血机制的纯概念中小型 SaaS 股**：
   - 痛点：依赖低息廉价资金与股权激励维持高营收增长，在无风险利率维持 4%–5% 宏观环境下，高倍估值面临永久性坍缩，无法产生正向自由现金流。
2. **高杠杆商业地产写字楼信托 (Office REITs)**：
   - 痛点：受远程办公常态化与再融资利率飙升双重夹击，空置率飙升，资产重估减值压力巨大，股息削减或暂停，下行通道极深。
3. **专利断崖的二线传统制药公司**：
   - 痛点：核心重磅药物专利期届满后面临仿制药悬崖式竞争，研发管线未见接续爆款，营收与利润大幅断崖。
4. **Meme 股票与散户情绪博弈高做空标的 (如 GME, AMC 等)**：
   - 痛点：缺乏底层商业模式支撑，价格完全脱离现金流折现模型，受 Reddit/社交媒体情绪脉冲驱动，波动剧烈且做空借券摩擦成本高昂，严重破坏中枢量化形态。

## 4. 美股实盘交易机制与量化适配要求

量化策略在美股运行时已由底层 `us_trading=True` 完全建模：
1. **单股精细化下单 (1-Share Lot Sizing)**：美股不强制 100 股整手交易，支持以 1 股为单位的高精度资金配比（`min_shares=1`），大幅降低组合再平衡摩擦损耗。
2. **SEC 交易费 (SEC Section 31 Fee)**：美股仅在卖出交易时收取微量监管费用（约 `0.00278%`，由系统内置 `sec_fee_pct` 自动计提），买单无该项规费。
3. **无涨跌幅停牌限制与 T+0**：美股日内波动完全自由释放（无 $\pm 10\%$ 限制），支持 T+0 迅速纠错与动态对冲。
