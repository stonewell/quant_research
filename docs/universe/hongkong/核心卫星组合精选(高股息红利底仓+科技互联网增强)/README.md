# 港股核心-卫星组合股票池 (Core-Satellite Universe: Hong Kong Edition) 架构说明书

## 1. 股票池设计背景与量化起源

港股市场作为典型的离岸金融枢纽，兼具“美元无风险利率定价分母”与“中国宏观经济基本面盈利分子”的双重特性。在历史行情中，单一风格的量化配置往往面临严峻痛点：
- **纯科技/成长池的痛点**：港股成长股对美联储流动性、地缘局势及监管情绪极度敏感。在流动性紧缩或估值挤泡沫周期中，估值下杀幅度剧烈（恒生科技指数历史上曾出现超 60% 深度回撤），左侧抄底极易遭遇持续阴跌。
- **纯高股息/红利央企池的优势与局限**：在港股深度熊市与降息预期博弈期，高股息央国企（股息率普遍高达 6%–9%，且较 A 股具有显著 AH 折价）凭借南向资金（港股通）的确定性买入，展现出强大的下行防御韧性；但进入全面牛市或产业主升浪周期时，缺乏科技成长标的的超额弹性与爆发力。
- **核心-卫星 (Core-Satellite) 终极解决方案**：
  * **核心底仓 (70% 风险预算，16只)**：配置经受住宏观周期考验的港股高股息央国企、公用事业与特许金融垄断基础设施。依托 6%–9% 的高股息安全垫、高额自由现金流与极低 PB 估值，构筑穿越牛熊的防守反击基地。
  * **卫星增强 (30% 风险预算，6只)**：精选具备全球竞争壁垒的超级科技互联网、AI 基础设施、新能源车及战略资源超级龙头。借助千亿级股票回购、经营杠杆释放与海外出海增量，捕获指数级 Alpha 弹性。

## 3. 坚决排除的失血黑名单 (Blacklist)

港股市场做空机制完善、流动性分化极度严重，若盲目纳入以下类型资产，将严重拖累策略整体夏普比率：
1. **陷入债务重组与信用违约的内房股及物业股 (如中国恒大、融创中国、碧桂园、万科企业等)**：
   - 痛点：地产行业长周期去杠杆，销售回款困难，资产面临巨额减值准备，债务重组方案反复落空，股票面临长期阴跌缩水甚至清盘停牌风险。
2. **缺乏造血能力与未盈利的 18A 生物医药微盘股**：
   - 痛点：依赖股权融资研发，在高利率宏观环境下再融资窗口收紧，现金流断裂风险极高；做空机构容易集中融券砸盘，出现断崖式闪崩。
3. **老千股、细价股与仙股 (Penny Stocks)**：
   - 痛点：频繁采用“大比例合股、折价供股/配股、清洗中小股东”财技，缺乏实体业务支撑，日均成交额极低，严重缺乏流动性。
4. **长期毛利倒挂、深陷内卷价格战的尾部硬件与新势力造车**：
   - 痛点：单车毛利严重为负，缺乏规模效应与自我造血机制，估值泡沫极度脆弱。

## 4. 港股实盘交易机制与量化适配要求

港股交易机制与 A 股、美股存在关键差异，量化策略在执行时已由底层 `hk_trading=True` 完全建模：
1. **每手股数 (Board Lot) 限制**：港股不同标的的每手交易股数不同（如汇丰 400 股、腾讯 100 股、中海油 1,000 股、紫金 2,000 股）。系统内置 [`_get_hk_board_lot`](file:///home/stone/Work/github/quant/common/allocation_backtester.py) 函数进行精确整手数向上/向下规整，严禁碎股进入核心调仓指令。
2. **双边印花税与规费 (Dual-sided Stamp Duty & Levies)**：港股买入与卖出均需缴纳双边印花税及交易所规费（合计约 `0.1085%`）。策略需内置换手率摩擦抑制机制 (`min_weight_change=0.02`)。
3. **T+0 交易与无涨跌停限制**：港股无 10%/20% 涨跌幅熔断限制，支持日内 T+0 快速平仓止损。
