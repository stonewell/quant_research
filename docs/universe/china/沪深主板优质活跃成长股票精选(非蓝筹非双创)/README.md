# 沪深主板优质活跃成长股票精选 (非蓝筹、非创业板、非科创板)

## 1. 股票池定位与设计初衷

本股票池专为解决量化策略在 A 股回测与实盘中的三大核心痛点而设计：
1. **严格排除大盘蓝筹/中特估垄断巨头 ("非蓝筹")**: 
   - 彻底剔除四大行、两桶油、三大运营商、煤炭电力央企及超大盘白酒消费等万亿级/千亿级超大盘股。
   - **痛点规避**: 传统大盘蓝筹贝塔钝化、换手率低，且极易在宏观“中特估/高股息风格轮动”与“成长风格”切换时发生集体风格脱钩下杀。
2. **严格排除双创板块 ("非创业板、非科创板")**:
   - 绝无任何创业板 (`300xxx`, `301xxx`)、科创板 (`688xxx`, `689xxx`) 及北交所股票。
   - **机制优势**: 交易规则保持在沪深主板 **$\pm 10\%$ 标准涨跌幅限制**（无 $\pm 20\%$ 宽幅波动剧烈冲击风险，无需单独开通双创两融高门槛权限）。
3. **聚焦主板中盘高弹性“新质生产力”与“隐形冠军” ("优质活跃")**:
   - 资产规模集中于 **200 亿 – 800 亿元** 的中盘成长与行业细分龙头。
   - **流动性充沛**: 40 只标的在 2022–2026 年平均日均成交额高达 **14.8 亿元 RMB/日**，无流动性折价或小微盘踩踏风险。
   - **弹性与趋势性俱佳**: 年化波动率分布在 **$30\% – 55\%$** 区间，具有清晰的波段趋势与中枢结构，极其适合缠论一二三买、动量突破与四态操作机策略。
