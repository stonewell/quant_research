# 核心-卫星组合股票池 (Core-Satellite Universe) 架构说明书

## 1. 股票池设计背景与量化起源

该股票池诞生于针对 A 股全市场 40+ 标的多轮步进前向回测（Walkforward 15 Folds, 2022–2025）的深度定量审计：
- **纯成长/双创股票池的痛点**：在熊市及结构性熊市（2022–2024）中，中枢突破频繁出现“假突破、暴跌洗盘”，且单票下行周期极度漫长（如宁德时代在产能价格战中持续阴跌，抄底损失惨重），尾部最大回撤高达 13.2%。
- **纯央国企高股息池的优势与局限**：在熊市中具备极强防守能力（夏普比率高达 1.30，最大回撤压制在 3.67%，逆势实现 16.39% CAGR），但在全市场牛市爆发期，缺乏高弹性成长标的的超额弹性。
- **核心-卫星 (Core-Satellite) 终极解决方案**：
  * **核心底仓 (70% 风险预算)**：配置 17 只经受住熊市考验的央国企高股息蓝筹，提供稳健安全垫与穿越周期的正向 Alpha。
  * **卫星增强 (30% 风险预算)**：配置 5 只各自主赛道不可或缺的超级产业龙头（CPO算力、半导体设备、铜金资源、汽车零部件出海），捕获主升浪十倍股弹性。

## 3. 坚决排除的失血黑名单 (Blacklist)

严禁在实盘与回测中将以下标的重新纳入该池：
1. **`300750.SZ` (宁德时代)**: 动力电池产能过剩与整车厂价格战，技术形态处于漫长均线空头压制期，左侧抄底反复打脸，历史累计造成 **-16,815 RMB** 亏损。
2. **`601186.SH` (中国铁建)**: 地产链深度承压，应收账款周期拉长，历史累计造成 **-11,642 RMB** 亏损。
3. **`600862.SH` (中航高科)**: 军工材料订单交付周期滞后，频繁假突破，造成 **-13,970 RMB** 亏损。
4. **`600584.SH` (长电科技)**: 半导体封测行业周期性弱复苏，假买点密集，造成 **-9,682 RMB** 亏损。
5. **`600487.SH` (亨通光电)** 与 **`600498.SH` (烽火通信)**: 光纤光缆行业价格战磨损，累计失血近 **-1.8 万元**。
6. **`688169.SH` (石头科技)**: 智能硬件国内降价内卷，多次击穿二买支撑，亏损 **-6,384 RMB**。

## 4. 实操执行指南 (CLI Commands)

### 1. 验证股票池解析
```bash
uv run --project pipeline python -c "
from common.universe import FileUniverseProvider
p = FileUniverseProvider('docs/universe/china/core_satellite_22_stocks.txt')
print('Loaded symbols:', len(p.get_symbols()), p.get_symbols())
"
```

### 2. 运行完整 Walkforward 步进回测
```bash
uv run --project pipeline python backtester/run_backtest.py \
  --universe-file docs/universe/china/core_satellite_22_stocks.txt \
  --strategy chan_four_state_blend \
  --walkforward \
  --folds 15 \
  --window-days 63 \
  --data-provider fuyao \
  --cache-dir data \
  --baseline-symbol 000300.SH \
  --results-dir pipeline/results/core_satellite_22 \
  --china-trading
```

### 3. 生成每日实盘交易信号与调仓计划
```bash
uv run --project pipeline python scripts/run_live_four_state_blend.py \
  --universe-file docs/universe/china/core_satellite_22_stocks.txt \
  --data-provider fuyao \
  --cache-dir data \
  --capital 1000000
```
