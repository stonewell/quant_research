# 核心-卫星组合股票池 100只精选 (China Universe Core-Satellite: 100 Stocks) 架构说明书

## 1. 股票池设计背景与量化演进

本股票池诞生于针对 A 股全市场多轮步进前向回测（Walkforward 2022–2026）的深度定量审计与实操适配：

- **原始 22 只股票池的局限**：原股票池（17只核心 + 5只卫星）在防守端表现优异，但在宏观赛道轮动、行业覆盖度以及承载大规模资金体量时，受制于标的样本偏少、单票特异性风险（Idiosyncratic Risk）未完全分散，且科技卫星端仅覆盖 5 个狭窄方向。
- **100只精选核心卫星组合的量化升级**：
  * **核心底仓 (Core Base: 58只，~60% 风险预算)**：精选沪深主板低估值、高股息央国企巨头与行业压舱石。覆盖国有大行、综合保险、石油石化、煤炭电力、公用事业水电、电信运营商、航运物流、大国基建、战略资源金属、工程机械与消费白马。具备极强护城河、充沛自由现金流与极低噪波，在熊市与震荡市构筑坚不可摧的本金安全垫与穿越周期的正向 Alpha。
  * **卫星增强 (Satellite Alpha: 42只，~40% 风险预算)**：精选全市场各主赛道最高景气与全球核心竞争力的成长领跑者。覆盖 CPO 算力网络、数通高频硬件、国产半导体与 CPU/GPU 算力芯片、先进封测、华为智驾与新能源汽车零部件出海、商业航天、AI 大模型与视觉物联网、工控自动化、以及光储与动力电池龙头。捕获结构性牛市与主升浪的十倍股弹性。
  * **流动性与容量**：100 只标的在 2022–2026 年平均日均成交额高达 **15.42 亿元 RMB/日**，全无微盘踩踏或流动性折价风险，完美匹配千万级以上实盘资金配置。
- **实盘小资金 (20万) 交易机制优化约束 (Price <= 250 RMB)**：
  * 在中国 A 股单手 100 股硬性限制下，单价超过 350 元的超高价标的买入 1 手即占用 3.5 万~13 万元（占 20 万账户 18%~65%），导致组合持仓严重失真；若目标仓位为 5%（10,000 元），系统计算股数不足 100 股将被向下取整至 0 股直接丢单。
  * **彻底剔除 6 只超高价标的**（贵州茅台 1299.56元、寒武纪 1109.00元、中际旭创 859.30元、北方华创 593.63元、新易盛 402.81元、宁德时代 358.10元）。
  * **保留 200 元附近高确定性 Alpha 领袖**（海光信息 250.43元、金山办公 247.36元、同花顺 227.03元、天孚通信 212.80元、澜起科技 198.35元、迈瑞医疗 167.75元、思源电气 140.30元、中芯国际 126.11元、沪电股份 120.72元）。
  * **精选 6 只优质核心/卫星高质量领军补齐 100 只（剔除失血内耗与暴雷黑名单标的后的优质增补）**：中国中车 (601766.SH)、华润三九 (000999.SZ)、三环集团 (300408.SZ)、光迅科技 (002281.SZ)、工业富联 (601138.SH)、银轮股份 (002126.SZ)。
