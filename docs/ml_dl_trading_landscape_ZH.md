# 机器学习/深度学习交易方案全景（AutoBNN 之外）— 研究综述

**状态：参考/综述文档，非实现计划。** 本文档中的任何内容均未接入本工作区的任何代码中，且未被任何 README 链接——与 `docs/TODO_autobnn_future_uses_ZH.md` 规范一致。本文件记录了针对 AutoBNN 之外近几年 (~2022-2026) 用于交易的 ML/DL 解决方案的深度研究综述，以备未来评估。

**核心结论：** 在研究的所有四个类别中，出现最一致的模式是“预测/分类表现良好”的强证据与“扣除真实交易成本后能否赚钱”的弱/负面证据。整个研究中最可信的结果是一个*负面*结果（§2，“股权组合深度时间序列模型基准测试”）。

---

## 1. Transformer / 状态空间预测模型

1. **Temporal Fusion Transformer (TFT)** (Lim et al. 2019/2021)：基于注意力机制的多预测时域模型，包含变量选择网络与分位数输出。
2. **PatchTST / Informer / Autoformer / FEDformer**：长序列预测 Transformer，在通用数据集上达到 SOTA，但在金融基准测试中并无突出表现。
3. **DLinear / NLinear** (AAAI 2023)：单层线性模型在长序列预测上击败复杂 Transformer，引发了对 Transformer 在时间序列中有效性的学术争议。
4. **iTransformer** (ICLR 2024 Spotlight)：反转序列轴，在特定股票预测上击败了多个预训练金融大模型。
5. **Mamba / 状态空间模型 (SSM)**：MambaStock 等模型的初步尝试，缺乏充分的成本后真实收益检验。

---

## 2. 时间序列“基础大模型” (Foundation Models)

评估模型包括：Amazon Chronos, Google TimesFM, Salesforce Moirai, Nixtla TimeGPT。
- **论文 1 (2026)**：在金融收益预测中，基础模型在绝大多数情况下与随机游走相比并无统计显著的超额收益。
- **论文 2 (2025)**：通用预训练时间序列大模型在金融收益上表现不佳，价值来自特定领域的金融预训练数据而非通用模型规模。
- **论文 3 (2026)**：测试 15 种深度架构，在考虑 20bps 交易成本后，**所有顶尖模型的净夏普比率均为负**。

---

## 3. 深度强化学习 (Deep Reinforcement Learning)

- **FinRL / FinRL-Meta / FinRL-Podracer** (AI4Finance)：开源 DRL 交易框架。作者汇报的无摩擦回测夏普比率较高。
- **DRL 过拟合检测**：通过假设检验估计 DRL Agent 的回测过拟合概率，低过拟合概率 Agent 在样本外崩溃期展现出较强鲁棒性。
- **学术界批评**：几乎所有 DRL 交易论文均假设零交易成本、无流动性约束，加入真实成本后超额收益基本消失。

---

## 4. 基于 LLM / Agent 的交易系统

- **TradingAgents / FinMem / FinGPT**：多 Agent 协作、分层记忆 LLM 交易系统。
- **核心风险**：**参数化前瞻偏误 (Parametric Look-Ahead Bias)**——预训练 LLM 的权重中已经包含历史股票走向知识，导致历史回测产生严重的数据泄露与过拟合。

---

## 5. 用于股票关系建模的图神经网络 (GNN)

- **HATS (2019)**：层次图注意力网络，通过层次注意力学习公司间关系（供应链、行业、所有权等），在分类准确率和纸面组合夏普比率上有一定提升。
- **局限**：绝大多数 GNN 论文仅评估分类指标（准确率/F1），几乎不评估扣除成本后的回测表现。

---

## 6. 总体结论

1. 没有任何被调研的方案达到“经独立、含成本、样本外验证可直接用于实盘”的标准。
2. 基础大模型和强化学习在不计成本时表现亮眼，计入交易成本和前瞻偏误后优势急剧衰减。
3. 这与 `bnn_forecaster` 的体验一致（机制通畅，但实际预测校准与扣费后 alpha 需谨慎评估）。
