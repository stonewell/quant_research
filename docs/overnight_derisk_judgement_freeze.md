## 1. 性质声明（先写定位，再写数字）

### 1.1 这是什么

`R6` 是**「收盘前决定、当日收盘 / 收盘集合竞价附近执行」的降隔夜暴露（overnight de-risking）**：

- 它回答的唯一问题是：**「今晚愿意带多少市场暴露穿过隔夜跳空？」**
- 决策在**一个由会话收盘时刻反推出来的固定时点**做**一次**，关心的是**夜里**，不是接下来十分钟；
- 输出是**市场层的目标权重乘数**（`1.0` 或 `0.5`），乘在**非现金代理**标的上；现金代理权重**不动**，差额**留现金**。

### 1.2 这明确不是什么

1. **不是日内择时**：不预测日内路径、不做盘中多空切换、不做 bar 级进出场。
2. **不是逐标的选择**：判据内**没有 symbol 维度的排序或判别**。跳空序列是**横截面等权均值**（见 §3 的披露简化），不是「挑出要减的股票」。
3. **不是波动率目标化叠加层**：本判据的 `σ_gap` 是**隔夜跳空幅度**的离散度读数，不是收益率的已实现波动预测，也不与任何策略自身的 vol-target 参数合并。

### 1.3 与 `M3.2` 负结果的关系（既不互相证伪，也不互相支持）

- `M3.2` 检验的是**成交价口径的系统偏差**（「窗口 VWAP 作为成交价是否偏离引擎记账价」），**被解释变量是成交价**；
- `R6` 检验的是**隔夜跳空风险是否值得在收盘前减仓**，**被解释变量是隔夜收益**。

被解释变量不同 ⇒ `M3.2` 的负结果**既不构成**对 `R6` 的否定证据、**也不构成**支持。`R6` 只能由它自己的验收用例独立成立，或独立按**负结果结项**（后者完全允许，见 §2.20 表头「本表是待验证的假设清单」）。

### 1.4 数字来源的诚实披露（不伪造文献）

`45min` / `W=20` / `252` / `m=2.0` / `ρ=0.5` 全部是**业主固定的运维风险预算约定**（2026-11-07 批准），**不是**经样本优化的参数、**不是**任何论文的引用值，也**不是**「已标定最优」。实现与文档**不得**为它们编造学术出处。

## 2. 判定时点（冻结）

**冻结值**：

```
D(market, day) = session_close_time(market, day) − 45min
```

- **必须**经 [`common/market_clock.py`](file:///home/stone/Work/github/quant/common/market_clock.py) 的 `session_close_time` / `MarketSpec.close_time_on`（**半日市感知**）计算；**禁止**写死 `14:15`。
- 由此得到的四个基准点：

| 市场 | 全日收盘 | 全日 `D` | 半日收盘 | 半日 `D` |
| :--- | :--- | :--- | :--- | :--- |
| A 股（`china`） | 15:00 | **14:15** | 无（`CHINA_EARLY_CLOSES` 全空） | — |
| 美股（`us`） | 16:00 | **15:15** | 13:00 | **12:15** |
| 港股（`hk`） | 16:00 | **15:15** | 12:00 | **11:15** |

- 返回值为**带时区的市场本地** `datetime`（`Asia/Shanghai` / `America/New_York` / `Asia/Hong_Kong`），**不是** host 时区，**不是** naive。
- **守卫（硬性）**：若 `D >= 收盘` 或 `D <= 当日开盘`（`MarketSpec.morning_open`）⇒ **抛错**，绝不静默继续、绝不夹到边界。`session_date` 必须是 `datetime.date`（不能是 `datetime`，那是 `date` 子类但永不等于 `date`）。

### 2.1 为什么是「收盘前 45 分钟」而不是某个整点

`45min` 是**业主的风险预算约定**：给「收盘前决策 → 收盘 / 收盘集合竞价成交」留出下单、复核、券商确认的时间，同时把决策点压在**当日尾盘之前**。它不是从数据里估出来的最优值。

### 2.2 为什么**必须**由会话收盘时刻反推（而不是固定 wall clock `14:15`）

固定 wall clock 的写法在**美股 / 港股半日市**会**晚于收盘**：美股半日 13:00 收盘时，`14:15` 已经是收盘后 75 分钟，`15:15`（美股全日对应的写法）在半日同样晚于收盘；港股半日 12:00 收盘时，`15:15` 晚于收盘 3 小时 15 分。此时决策会读到「价格已经被取走之后」才存在的 bar ⇒ **取价未来函数**（look-ahead）。因此时点**只能**由 `session_close_time(market, day)` 反推，半日市自动前移，守卫在几何不成立时直接抛错。

同一理由也解释了为什么 `r6.1`（`14:45` 固定 wall clock + 5m bar）被本判据取代用于实盘消费面：`r6.1` 的 §2.1 只证明了 `14:45 < 15:00`（A 股全日），**没有**证明它在美股 / 港股半日市下仍早于收盘；且 `r6.1` 依赖 5m 面板，而本条的冻结值不依赖 5m（见 §8）。

### 2.3 `D` 与判据的**因果次序**

判定只允许使用「在 `D` 时刻**已经存在**」的信息。本判据的信息集是**日线**：`Open_t` / `Close_{t−1}`（见 §3）。`Close_t` **不在**信息集内（§6 的用例 6 用「扰动 `Close_t` 不改变 `gap_t`」钉死这一点）。

## 3. 触发谓词（冻结）

**定义**：

```
gap_t = (1 / N_t) · Σ_i ( Open_{i,t} / Close_{i,t−1} − 1 )
```

- 对**当日有相邻两日 bar** 的标的取**等权横截面均值**；`N_t` 是这些标的的数量（`symbols_used`）。
- **披露的简化（HONEST DISCLOSURE）**：真实的组合隔夜跳空是**持仓权重加权**的 `Σ_i w_i · (Open_{i,t}/Close_{i,t−1} − 1)`，本判据用**横截面等权均值**代理。理由：判据必须在**权重尚未定稿 / 权重每日变动**时即可计算（它就是用来决定权重的），用当日权重会形成「判据依赖它自己要修改的量」的循环；等权也是唯一不需要第二个输入（持仓簿）的可复算口径。代价：组合实际跳空与 `gap_t` 之间存在权重偏离，**不得**把 `gap_t` 读成「本组合昨晚实际亏了多少」。举证字段：每日的 `symbols_used`（`N_t`）。
- **只取有相邻两日 bar 的标的**：`Open_{i,t}` 与 `Close_{i,t−1}` 都必须是有限值。缺任一 ⇒ 该标的当日**被排除并计数**，**不得插值、不得 fillna(0)、不得用「前一个可得收盘」代替 `Close_{t−1}`**。`0.0` 是一个合法跳空值（平开），缺失不是；把缺失写成 `0.0` 会让「没数据」在下一层看起来像「平开」。

**统计量与基线**：

```
σ_gap(t) = std( gap[t−W+1 .. t] )，W = 20（样本标准差，ddof=1）
B(t)     = median{ σ_gap(s) : 以 t 结尾的最近 252 个交易日 }
触发     ⇔ σ_gap(t) > m · B(t)，m = 2.0（严格大于）
```

- `B(t)` 的 252 个元素是**σ 值**（每个 σ 本身已消耗 20 个 gap 日），因此**满基线需要至少 `252 + 19 = 271` 个有效 gap 日**。
- **不足判定（`INSUFFICIENT_DATA`）**：有效 gap 日不足 `W=20`，或**可得 σ 值不足 252**（即基线窗口不满）。二者都以显式状态表达，**不得**用更短的窗口凑一个 `B(t)`、**不得**用 `σ_gap(t)` 自身填充基线、**不得**把不足当成「未触发」。
- **边界方向固定为严格 `>`**：`σ_gap == 2·B` **不触发**。理由：`m=2` 是「异常放大」的判定线，取含等号会让「恰好两倍」这一测度为零的边界也触发，而 `>` 与 `>=` 在连续量上无实质差别，选择记录在此以便复算。

## 4. 下调比例（冻结）

**冻结值**：`ρ = 0.5`，并**硬断言 `0 < ρ < 1`**（构造即校验；`0.0` = 清仓、`>= 1.0` = 不加杠杆，二者都超出本条语义 ⇒ `ValueError`）。

应用规则：

- **只乘非现金代理**的目标权重；**现金代理权重不动**，差额**留现金**（不重新归一化整个簿 ⇒ `Σw` 会低于 1，这是**有意**的：现金正是被留下的那部分）。
- 显式 `0.0` 乘后仍是 `0.0`（不是 `NaN`、不是缺键）。
- 输出**永不含 `NaN`**；输入含 `NaN` ⇒ `ValueError`（权重里的 `NaN` 正是本仓库 `NaN`-vs-`0.0` 事故类）。
- `NOT_TRIGGERED` / `INSUFFICIENT_DATA` ⇒ 乘数 `1.0`，返回的映射与输入**逐位相等**（float-for-float），不做任何归一化、舍入或键序变化。

### 4.1 现金代理的判定来源（不新造标的清单）

「哪些目标权重是现金」**不得**由本判断自行发明，取两个既有权威的交集式并集：

1. `cash_proxy` —— 本次运行的现金停泊标的（`params["cash_proxy"]`，默认 `BIL`），即 `model_cash_target` / 第三级熔断的 100% 现金切换 / Phase 4 cash sweep 使用的**同一个**符号；
2. `common/allocation_backtester.py::CASH_PROXY_SYMBOLS` —— 仓库既有的「自身价格已携带无风险利率」的标的集合（T-bill ETF / 货币 ETF / 1 日逆回购）。

匹配按**裸代码**（去交易所后缀、大小写折叠），因为既有集合存 `511880`、宇宙里常写 `511880.SH`。`apply_overnight_downscale` 内部仍是**精确键匹配**（不做模糊匹配，以免静默豁免真实风险标的），故调用方必须传入「目标键中属于现金的那些键」，而不是规范化后的拼写。

## 5. 三态词表（封闭）

| 状态 | `ratio` | 含义 | 消费方必须做什么 |
| :--- | :--- | :--- | :--- |
| `TRIGGERED` | `ρ = 0.5` | `σ_gap > 2·B` ⇒ 隔夜暴露按冻结比例下调 | 非现金权重乘 `ρ`，票据落显式字段 |
| `NOT_TRIGGERED` | `1.0` | `σ_gap <= 2·B` | 乘 `1.0`（等价于不动），**不做任何附带改动** |
| `INSUFFICIENT_DATA` | `1.0` | 无法判定（§3 不足条件） | **不降暴露**，但**必须**在 ticket 落显式字段 + stdout `WARN` |

**`INSUFFICIENT_DATA` 的语义（用户 2026-11-07 裁定）**：

- 它**既不等同于**「未触发」，**也不等同于** `0`：它不降暴露（`ratio` 为 `1.0` 只是「没有任何乘数被应用」的记账值），但**必须在票据上显式可读**并被 `WARN` 告警。
- 默认**不拒票**：数据不足只告警，不阻断开单。这是与 `INSUFFICIENT_DATA` 在其他条目（例如 Stage 1 净值门禁）里的严格语义**刻意不同**的一处，理由：本条是**降暴露**的加成层，缺少它等价于「按原策略出票」，而不是「无风险结论」；把缺数据升级为拒票会让实盘在数据缺口的每一天都停摆，风险面远大于收益。
- 禁止的读法：把 `1.0` 读成「已经评估过且没触发」，或把 `INSUFFICIENT_DATA` 读成 `0.0`（清仓）。票据字段必须同时携带 `status` 与 `reason`，**不得**只落 `ratio_applied`。

## 6. 取价顺序的结构性保证（为什么这不是未来函数）

回测/实盘的两种相关取价口径（见 `common/allocation_backtester.py::EXECUTION_PRICE_MODES`）：

- `close`：取价点是**当日收盘**；
- `intraday_twap`：取价点是**当日全部 5m 典型价的均值**，其最后一个切片**不早于收盘前一根 bar**。

`D = 收盘 − 45min` 对二者都**严格更早**。实现必须显式断言：

```
decision_instant < pricing_point
```

违反即**抛错**。`pricing_point` 对 `close` 是当日收盘瞬时；对 `intraday_twap` 取当日会话内**最后一个 5m bar 的结束时刻**（≤ 收盘），断言因此退化为 `D < 收盘 − 0`，仍严格成立。

**可测形式**：把 `minutes_before_close` 改成负数（或任何把 `D` 推到收盘之后的取值），§7 的守卫用例必须**转红**；把 `D` 推到收盘之后同时会让「`close` 与 `intraday_twap` 决策序列一致」这一结构断言失效 —— 因为 `D` 之后才会出现的价格进入了信息集。

## 7. 默认与失效条件

- **默认开启**：`enabled` 默认 **`True`**（用户 2026-11-07 裁定）。CLI：`--enable-overnight-derisk` / `--no-enable-overnight-derisk`（默认开），`--overnight-derisk-ratio`（默认 `0.5`，越界即 `ValueError`）。
- **预注册值不是「已标定最优」**：`45 / 20 / 252 / 2.0 / 0.5` 是**占位基线**。任何调参**必须**先在本文以修订段重新注册（写明旧值、新值、依据、失效条件），再改实现；**禁止**在实现里「顺手调参」或把未注册的魔数塞进默认值。
- **失效条件（预注册，供未来结项/复检判定）**：
  1. **判据失效**：`σ_gap > 2·B` 的触发日与随后的隔夜跳空**没有**正向关系（即触发日之后的隔夜收益分布不劣于非触发日）⇒ 判据不成立；
  2. **收益失效**：长期看「触发日减半隔夜暴露」的净收益（含摩擦成本）**不优于**不做该下调；
  3. **样本失效**：`252` 个基线窗口在实盘数据上长期无法满足（大面积 `INSUFFICIENT_DATA`）⇒ 该判据在现有数据面上不可评估，应降级为「待确认」并重新设计窗口，而不是悄悄缩短窗口；
  4. **口径失效**：日线 `Open/Close` 无法覆盖组合的主要风险源（例如组合以港股 / 美股为主而日线数据存在系统性缺口）⇒ 代理口径失效。
- **负结果结项是被允许的结局**：若离线研究证伪上述任何一条，按**负结果结项**（保留模块、关闭默认），**不得**事后粉饰为「机制正确、只是样本不够」。

## 10. 验收与「反向改坏即转红」留痕

| 编号 | 验收项 | 反向改坏（必须转红） |
| :--- | :--- | :--- |
| ① | `TRIGGERED` ⇒ 非现金权重 ×`ρ`，现金代理不动，显式 `0.0` 仍为 `0.0`，总和按差额减少（不重新归一化） | 删掉触发分支 / 改成归一化后再乘 |
| ② | `NOT_TRIGGERED` ⇒ 逐位等于输入 | 让未触发分支返回任何改动（含舍入 / 归一化） |
| ③ | `INSUFFICIENT_DATA` ⇒ 不降暴露、字段显式、`WARN`，且**不等于** `NOT_TRIGGERED` | 把不足分支折进「未触发」（状态相等 / 无 `reason`） |
| ④ | `D` 在收盘之后 ⇒ 抛错 | `minutes_before_close = -5`（或把守卫删掉） |
| ⑤ | 半日市 + 时区：US 半日 13:00 ⇒ 12:15、HK 半日 12:00 ⇒ 11:15、A 股全日 ⇒ 14:15，且为 tz-aware 本地时间 | 写死 `14:15` / 忽略半日市 / 返回 naive |
| ⑥ | `gap_t` 只消费 `Open_t` 与 `Close_{t−1}`（扰动 `Close_t` 不改变 `gap_t`） | 用 `Close_t` 参与 `gap_t`（把 `shift(1)` 删掉或改成 `shift(-1)`） |

实测的「改坏 → 转红 → 还原 → 复绿」留痕记在 `R6` 的结项附注中；本文只钉住「改哪里必须转红」。

## Revision 2026-11-07b (r6.3)

> **性质**：按文首「修订方式」追加的 **append-only** 修订段。**上方全部冻结文本原样保留**（可追溯），本段在其上**覆盖**与 `r6.2` 冲突的部分；冲突时本段优先。规则规格号由 `r6.2` 升至 **`r6.3`**（实现侧常量 `common/overnight_derisk.py::DECISION_SPEC_VERSION`）。
> **触发原因**：独立复核（2026-11-07）发现 `r6.2` 的**横截面集合**取自「当日目标簿」，与本文 §3 自己的披露理由**互相矛盾**（§3 明写等权的优点正是「唯一不需要第二个输入（持仓簿）的可复算口径」，而实现却把持仓簿当成了唯一的输入）。用户 2026-11-07 裁定：横截面改为**本次运行已加载的 universe（按市场分组）剔除现金代理后的全集**。

### 1. 唯一变更：横截面集合（`N_t` 的分子集合）

**`r6.2`（被取代）**：横截面 = 当日**目标簿**中的非现金标的（`current_targets.index` 剔除现金代理）。
**`r6.3`（现行）**：横截面 = **本次运行已加载 universe 中、属于该市场、且不属于现金代理集合的全部标的**。

复算定义（逐字可复现）：

```
C           = resolve_cash_proxy_target_symbols(universe.keys(), cash_proxy)
              = { i ∈ universe : bare(i) ∈ {bare(cash_proxy)} ∪ {bare(s) : s ∈ CASH_PROXY_SYMBOLS} }
              （bare(·) = 去交易所后缀、大写折叠；来源：本次运行的 cash_proxy 与
                common/allocation_backtester.py::CASH_PROXY_SYMBOLS，不新造标的清单）
U(m)        = { i ∈ universe \ C : market_of(i) = m }
              market_of(i) = infer_market_from_symbol(i)；无法识别时回退本次运行的
              clock_ctx.market 并打印一条含该标的名的 INFO/WARN（不改判据数值）
gap_t       = (1 / N_t) · Σ_{i ∈ U(m), i 当日可用} ( Open_{i,t} / Close_{i,t−1} − 1 )
N_t         = |{ i ∈ U(m) : Open_{i,t} 与 Close_{i,t−1} 均为有限值，且 Close_{i,t−1} > 0 }|
σ_gap(t)    = 20 个连续 gap 日的样本标准差（ddof=1），基线 B(t) = 最近 252 个 σ 的中位数
触发         ⇔ σ_gap(t) > 2.0 · B(t)（严格大于）
```

- **`U(m)` 由已加载 universe 决定，与目标簿无关**：目标簿只决定「乘数乘在哪些权重上」，**不再**决定「σ 在哪些标的上估」。
- **绝不回退到目标簿**：`U(m)` 为空（例如该市场的 universe 标的全部是现金代理，或该市场在 universe 中缺帧）⇒ 该市场 `N_t = 0`、gap 全 `NaN` ⇒ `INSUFFICIENT_DATA` + `WARN` + 不降暴露（**无任何** book-fallback）。
- **不得纳入 universe 之外的标的**：不在 `universe` 映射里的符号一律不进入 `U(m)`；这不是「尽量多取几个」，而是可复算的集合定义。
- **缺失仍是排除并计数**：无相邻 `Open_t` / `Close_{t−1}` 对的标的不进入 `N_t`，**不插值、不 fillna(0)、不用「前一个可得收盘」代替**（与 §3 完全一致，本次不动）。
- **未变（本段一字不改）**：`D = session_close_time(market, day) − 45min` 及半日市守卫（§2）、`W=20` / 基线 `252` / `m=2.0` 严格 `>`（§3）、`ρ=0.5` 且只乘非现金代理、差额留现金、不重新归一化（§4）、三态词表与 `INSUFFICIENT_DATA ⇒ ratio = 1.0` + `WARN` + 不拒票（§5）、取价顺序断言（§6）、`enabled` 默认 `True`（§7）、边界与非目标（§8）、可观测字段（§9，其中 `symbols_used` 现为 `N_t`，取自 `U(m)`）。

### 2. 取代理由（四条，均为可核对的事实）

1. **簿依赖（book dependence）**：`r6.2` 的 σ 是「今天恰好持有的标的上」的跳空离散度。同一市场、同一天、同一份行情，只因为持仓簿不同，σ_gap 就不同 —— 判据因此依赖了它自己下游的输出，构成 §3 明令避免的循环。
2. **轮动不稳定（rotation instability）**：目标簿随策略轮动而变，`N_t` 在 2 到数十之间跳变；2 个标的的样本标准差与 20 个标的的样本标准差不是同一个统计量，触发状态会因**策略轮动而非风险变化**翻转。这是把「风险判据」退化成「持仓数量判据」。
3. **历史 σ 的未来函数（historical-σ look-ahead）**：基线的 252 个 σ 值本应用「当时就可得的横截面」计算；用**今日**目标簿去重算历史，等于用今天的信息集改写昨天的 σ，触发阈值随之漂移 —— 与本文 §2.3「判定只允许使用 `D` 时刻已经存在的信息」不相容。
4. **与本文 §3 自身理由矛盾**：§3 披露等权代理的理由是「它不需要第二个输入（持仓簿）」，并以此论证可复算性；`r6.2` 的实现恰恰把持仓簿变成了唯一输入。本段消除该矛盾。

### 3. 残余限制（如实披露，不粉饰）

- **universe 漂移仍会影响历史 σ。** `U(m)` 取的是**本次运行解析出的** universe；同一个 `as_of` 日、同一份行情，若两次运行的 universe 成员不同（增删标的、`--universe-file` 变更、持仓把它带进加载集合），历史 `gap_t` 与 `σ_gap` 会不同，触发状态也可能不同。本段只消除了**目标簿**这一维依赖（那是会每日轮动、且与判据本身构成循环的一维），**没有**消除 universe 维依赖。冻结口径如实记为「以本次运行的 universe 快照回看历史」，**不得**被读成「σ 历史绝对不变」。
- **持仓带进加载集合的标的也会进入 `U(m)`。** Stage 2 会 `universe_symbols ∪ held_symbols` 一起加载（`scripts/run_live_strategy.py` 的 `symbols_to_load`），因此「账本里有、策略池里没有」的标的是 `U(m)` 的成员。这是**有意的**：它们是真实暴露；但它也意味着「换一份持仓账本」同样会移动 `U(m)`。这是 universe 维限制的一个具体来源。
- **市场归属依赖符号推断。** `infer_market_from_symbol` 无法识别时回退本次运行的 `clock_ctx.market`，并在 stdout 点名该标的。若某次运行中该回退覆盖了 `U(m)` 的多数成员，市场归属实际未被验证，本次判定的 `D` 与横截面都只是一次「假设同市场」的计算。
- **样本量口径仍按标的计数，不按市值加权。** §4.1 的权重偏离披露继续有效，本段未改。

### 4. 不得叠加（冻结条款）

`r6.1`（固定 `14:45` + 5m 日内回撤）、`r6.2`（横截面取自目标簿）、`r6.3`（横截面取自 universe 剔除现金代理）是**三套**判据规格，**`r6.1` / `r6.2` / `r6.3` 判据不得叠加**：同一份目标权重**同一时刻只允许一套规则接线**。叠加会把两次 `0.5` 乘成一次谁也没有冻结过的 `0.25` 下调。`r6.2` 的正文与实现留痕保留以便追溯，但其**横截面定义**已被本段取代，不得再接线。

### 5. 失效条件（追加，与 §7 并列生效）

除 §7 已冻结的四条失效条件外，本段追加两条（满足即须重新注册，而不是就地改代码）：

1. **代表性失效**：`N_t` 长期只覆盖目标簿风险源的一小部分（例如 universe 只剩 2–3 个可用标的，而簿的实际风险来自另外若干个），此时 `gap_t` 既不代表簿、也不再是可比的统计量 ⇒ 该判据在当前 universe 上不可评估，应降级为「待确认」并重新设计横截面（例如预注册固定研究 universe），**不得**以「反正不再看簿了」为由继续接线。
2. **可复现性失效**：同一 `as_of` 日、同一行情快照下，因 universe 成员变动导致 `status` 在两次运行间翻转（且两次运行的目标簿相同），说明判据读数主要由 universe 口径漂移驱动而非风险变化 ⇒ 按 §3 的残余限制处理：要么冻结 universe 快照，要么按负结果结项，**不得**用「换一个 universe 就绿了」的方式维持接线。
