## 1. 性质声明（先写定位，再写数字）

### 1.1 这是什么

`R4` 回答一个问题：**「市场层这些票最近是不是在同一个方向上一块儿动 —— 以至于今天的市场暴露应当打折携带？」**

- 输出是**市场层目标权重的乘数**（`1.0` / `0.75` / `0.50`）**加上产出该乘数的证据**（`D`、`B`、比值、状态、原因、进了横截面的标的与被**剔除并计数**的标的）；
- 判据内**没有** symbol 维度的排序、挑选或选择：算子是**横截面摘要**（一个披露的代理量，代理「盘面还在承载多少独立信息」），不是「挑出要减的股票」；
- 它**不是**日内择时（不预测路径、不在盘中多空切换），**不是**波动率目标化叠加层（读数是**跨标的收益离散度**，不是任何单序列的波动预测，也不与任何策略自身的 vol-target 参数合并）。

### 1.2 算子（冻结）

在冻结的 5m 会话网格上（`48` 个 END 标签，标签 `t` 覆盖 `(t-5m, t]`，见 `common/intraday_synthetic.py`）：

```
r_i(t) = close_i(t) / close_i(t - 20 bar) - 1        # 20 根 bar 的收益（≈100 分钟）
D(t)   = std_{ddof=1}( r_i(t) )                       # 横截面等权样本标准差
B(t)   = median{ D(s) : 此前 20 个交易日同一 bar-of-day 的 D }
```

`20` 是 **bar 计数**（`RETURN_LOOKBACK_BARS`），不是交易日计数：「20 根 bar 之前」是**会话时钟上的位置**，因此实现在**完整网格**上做 `shift(20)`（`session_close_matrix` → `window_returns`），而不是在某个 symbol 自己的行序上移位 —— 否则一个洞就会静默地把回看长度改掉。

### 1.3 为什么是 `std`，不是 `MAD`（本条最容易写错的地方）

`R4` 行原文否决 MAD 的理由必须逐字保留：「标准差对单只极端值敏感、MAD 更稳健但在小样本 / 高同向时可能退化为 0」。落实到实现：

- **MAD 的退化方向是「伪造崩塌」**：只要横截面里**过半**标的名次并列（小样本、高同向日正是本规则要判的场景），`MAD = 0.0`，而 `0.0` 与「最深一级崩塌」在比值上不可区分 —— 一个并列的算术副产物会被读成最强风险结论；
- **`std` 的退化方向是「漏报」**：一只极端标的会把 `D` 抬高，从而**掩盖**真实崩塌。对首轮 advisory 的降险叠加层，这是**安全**的那一侧（少减而非多减），且被 §9 的验收第③条钉死：单只极端值**不得**冒充崩塌。
- 本文与实现**不**用 MAD、**不**用「标准差与 MAD 的较小者」、**不**在两者间切换；判据只有一条。

## 4. 判据、状态词表与边界约定

**四态闭合词表**（`CsdStatus`，`.value` 字符串即落盘契约）：

| 状态 | 乘子 | 语义 |
| :--- | :--- | :--- |
| `NORMAL` | `1.0` | `D > 0.75·B`；返回**字面量** `MULTIPLIER_UNCHANGED`，不是 `min(1.0, …)` 算出来的浮点。 |
| `LIGHT_COLLAPSE` | `0.75` | `0.5·B < D ≤ 0.75·B`。 |
| `COLLAPSE` | `0.50` | `D ≤ 0.5·B`。 |
| `INSUFFICIENT_DATA` | `1.0` | 不可测量。**既不是** `NORMAL`，**也不是** `0.0`。 |

**边界约定（`≤` 即降，且被测试钉死）**：两条带的等号都归**更重**的一侧 —— `D = 0.5·B` 属于 `COLLAPSE`（不是 `LIGHT_COLLAPSE`），`D = 0.75·B` 属于 `LIGHT_COLLAPSE`（不是 `NORMAL`）。用 `≤` 而非 `<`：阈值是**风险预算**，恰好触到预算即视为预算已达。等价地，实现先判重带、再判轻带。

**`INSUFFICIENT_DATA` 的两种子情由 `reason` 分辨**（状态词表不因此扩张）：

1. **横截面太薄** —— 有效标的 `< 8`：`multiplier = 1.0`、**`dispersion = None`**（绝不 `0.0`）、`baseline = None`。
2. **基线不可用** —— 此前可用 `D` 的会话数 `< 20`（或基线非正）：`multiplier = 1.0`、`dispersion` 保留真实读数、`baseline = None`。

「基线不足」与「横截面不足」是**两件事**，不得合并成一个 `None`：前者说「今天测得到，但没有可比历史」，后者说「今天根本测不到」。绝不使用更短的基线窗口，也绝不在基线不足时读成「未触发」（与 `common/overnight_derisk.py:60-61` 同一纪律）。

**样本完整性（剔除并计数，绝不插值）**：某 bar `t` 仅对「`t-20 .. t` 共 21 根 bar 全部在网格上」的标的取用；窗内缺任一根 ⇒ 该标的进入 `symbols_dropped`，**不**前填、**不**插值、**不**跨洞拼接。跨洞的「20 bar 收益」覆盖的是一个未知长度的时间跨度，不是 100 分钟。

## 5. 最小横截面 8 与 `MIN_CROSS_SECTION_ASSETS = 15` 的关系（必写）

- `common/signal_snapshot.py::MIN_CROSS_SECTION_ASSETS = 15` 服务的是 **Rank IC / IC-IR** 那一族估计：单日横截面不足 15 个标的时，名次统计量本身不可靠，故 `common/ic_decay_monitor.py` 把该日**排除并计数**（绝不是填 `0.0`）。
- `R4` 的 8 服务的是**市场层去险**：判据只用一个**二阶矩摘要**（等权样本标准差），它**不依赖**逐腿 IC 的显著性、不做名次、不做回归、不做分位；8 个样本已能给出一个非退化的离散度读数（`ddof=1` 要求至少 2，8 是留了安全裕度的工作门槛），而 15 会把「市场层只有 10 个标的」的小宇宙直接判成永远不可测 —— 那等于给小宇宙**永久豁免**降险，比门槛偏低更危险。
- 两者**不共享常量**、**不互相覆盖**：`R4` 的 8 只在 `common/cs_dispersion_exposure.py` 内定义，`signal_snapshot` 的 15 仍是 IC 族唯一出处。**禁止**为了「统一口径」把任一方的常量改写成另一方的值。
- 与既有「现金代理剔除」一并生效：8 的计数是**剔除现金代理之后**的标的数。

## 6. 与 `R1` / `R7` 的边界（不得合并、不得互调）

- **与 `R1`（日内回撤 → 目标暴露下调）**：`R1` 的被解释量是**单个组合的日内回撤幅度**（`hwm_intra` / `dd_trough`），`R4` 的是**横截面结构**（跨标的收益离散度）。`R4` 行第 5 条原文：「与 `R1` 是**两个独立判据**（回撤幅度 vs 横截面结构），**不得**合并成一条，也**不得**互相复用阈值或互相调用。」本实现**不**读 `hwm_intra` / `dd_trough`，**不**引用 `R1` 的阈值，也**不**提供任何把两者相乘的「综合风险分」。
- **与 `R7`（缺 5m ⇒ 冻结新开仓）**：`R7` 拥有「缺数据 ⇒ 新开仓置零」的语义。`R4` 只做两件事：把窗内不完整的标的**剔除并计数**，以及在此之上给出市场层乘数。`R4` **永不冻结订单**，也**不**改 `blend_base.py` 的 5m 开关默认值（仍全 `False`）。
- **与 `R6`（隔夜降险）**：同层（都作用于市场层暴露）但判据不同 —— `R6` 判隔夜**跳空幅度**、`R4` 判**横截面离散度**；两者阈值、窗口、时点各自独立，**不共享常量**。`0.50` 这个数字与 `R6` 同值属**引用既有降半语义**，不是复用其触发条件。

## 8. 失效条件与负结果预期（不得事后粉饰）

按 §2.20 表头「本表是**待验证的假设清单**」的纪律：

- `R4` 的收益前提（横截面同向化先于市场层下跌）**尚未在本仓库被证真**；落地后若测不出效果，**按负结果结项是预期结局之一**，不得写成「机制正确、只是样本不够」。
- 明确失效条件：①真实面板的 `D` 分布没有稳定的「相对自身历史」结构时，比值判据会退化为噪声（此时应以负结果结项，而不是继续调 0.75/0.50）；②`20 bar` 与 `20 日基线` 相位不一致的面板（例如只取上午 bar 的面板）会使 `D(t)` 与 `B(t)` 描述一天中的不同时段 —— 实现以 `bar_label` 固定相位，调用方**不得**在不同相位间混算。
- 全部验收用例 **100% 离线**、只用合成 5m 面板（`common/intraday_synthetic` 网格），不读生产缓存、不联网、不依赖 `backtests_research/`。

## 10. 与 `R4` 行措辞的偏离说明

| 行文措辞 | 本文落地 | 理由 |
| :--- | :--- | :--- |
| 「滚动窗口（bar 数或分钟数，须写明取值理由）」 | 冻结为 **20 bar**（≈100 分钟），不是「21 个 bar 的窗」 | 20 是**收益跨度**（`t-20 → t`），窗内共 21 根 bar 只是完整性判据；写 `20` 与 `gap_window = 20` 同形，避免「窗宽 / 跨度」两套数字。 |
| 「阈值（绝对阈值，还是相对自身历史的百分位）」 | 取**相对自身历史的比值带**（`D/B` 对 0.75 / 0.50），非绝对阈值、**也非百分位** | 绝对阈值不可跨 regime 比较；百分位在 20 个样本上不可靠（分位点由插值决定，且会在崩塌期自我锚定）。比值带只用 `median` 一个稳健点，边界可机械复算。 |
| 「离散度定义：标准差 vs. MAD 择一」 | **标准差（`ddof=1`，等权）** | 见 §1.3；MAD 的 `0.0` 退化方向是「伪造崩塌」。 |
| 「合成一个横截面收益高度同向塌陷的面板」 | 用例用**受控设计向量**构造 `D/B ≈ 0.70 / 0.30`，并在 8/10 并列时演示 MAD 退化为 `0.0` | 需要一个**可复算**的比值，而不是「看起来同向」的随机面板；边界等号另在 `classify_dispersion` 上用精确浮点钉死（复合价格算术无法表达精确等号）。 |
| 行内「消费面**待确认**」 | 本轮**不接线**，`advisory=True` / `gates_orders=False` | 首轮只交付纯函数与用例；接线是后续独立任务，须另行裁决。 |
