# 中频波段交易策略研究：三大类缠论实战体系

在现代股市的中频交易（持仓期通常为数周至数月）中，不局限于死板教条的缠论，而是吸纳其“结构、分形、多空博弈”底层逻辑的四大/三大核心策略体系如下：

## 策略一：价格行为学中的“交易区间突破与二次回踩”策略
- **核心逻辑**：市场绝大多数时间在进行横盘震荡与筹码交换（类中枢），趋势诞生于区间打破之后。
- **实战步骤**：
  1. 寻找日线级别横盘大于4周、且成交量萎缩的震荡箱体。
  2. 等待强力K线突破箱体上沿，切忌盲目追高。
  3. 等待突破后的缩量回踩，在原箱体上沿出现拒绝下跌形态时分批建仓。
  4. 止损设在箱体内部中轨或下沿下方。

## 策略二：筹码轮廓与“控制点（POC）迁移”中频策略
- **核心逻辑**：利用成交量轮廓（Volume Profile）追踪主力机构的平均成本中枢（POC）变化。
- **实战步骤**：
  1. 筛选过去3个月中 POC 呈阶梯式稳步上移的个股。
  2. 当股价因洗盘快速下探至前期筹码密集区（POC 或价值区下沿）时进行吸纳。
  3. 持股跨越数周，若乖离率过大或 POC 向下塌陷则分批止盈。

## 策略三：改良版波浪理论与“黄金分割”三浪主升策略
- **核心逻辑**：捕捉主升浪（第三浪）的爆发力，规避繁复浪型，专注核心数学规律。
- **实战步骤**：
  1. 寻找完成一浪温和上涨、进入数周缩量回调（二浪）的标的。
  2. 借助斐波那契工具确认二浪回调至 0.5 或 0.618 黄金分割位，且成交量萎缩至地量。
  3. 企稳并突破短期下跌趋势线时切入，捕获数月级主升浪。
  4. 目标位参考一浪高度的 1.618 倍进行分批止盈。
