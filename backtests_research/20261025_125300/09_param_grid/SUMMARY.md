### 3.1 三条读表要点

1. **MaxDD 方向按策略整体翻转**：`cdhb` 三臂 **全变差**（+0.16 / +0.01 / +0.21pp）、`crb` 三臂 **全变差**（+0.27 / +0.12 / +0.22pp）、`cfsb` 三臂 **全变好**（−0.17 / −0.01 / −0.08pp）⇒ **不存在跨策略一致的 ATR 结论**。这不是"幅度小"，是"方向随策略变号"。
2. **CAGR 侧没有一条单调曲线**：`cdhb` 25.6274 → 24.6247 → 25.2254 → 25.4683（第一步就掉头）；`cfsb` 30.1513 → 30.4500 → 30.2912（−0.159pp 反向）→ 33.5425。**两个策略都在 `6.0→8.0` 这一步反向**。
3. **Sharpe 侧全在噪声内**：三策略九臂的最大臂级 |ΔSharpe| 为 **0.1963**（`cfsb/atr_none`），相对本策略 `fold_sharpe_std` 2.2836 只有 **8.6%**；其余八臂 ≤ 0.1140。

### 3.2 `atr_6_0` / `atr_8_0` 是「一折宽」的噪声臂（`clip` 解释已撤回）

> **撤回声明**：本节旧稿曾写「两臂被 `np.clip(…, 3.5, 7.5)` **吸收**、名义步长在生效口径上被压缩到 7.5」。该说法**在本网格内不可检验、也与实测不符**，已撤回；下面只保留产物支持的读法。

- **`clip` 无法判定（不是发现）**：网格只有 `atr_6_0`、`atr_8_0`、`atr_none` 三个值，**没有 `atr_7_5` 臂** ⇒ "8.0 的生效值等价于 7.5" 属于**未测即不得断言**。`blend_base.py:896` 的 `eff_stop_mult = float(np.clip(stop_atr_mult * (med_vol / s_vol), 3.5, 7.5))` 确实存在，但本批没有任何臂能标定它把 8.0 压缩到什么位置。
- **但两臂也不是近似空操作**：逐折 ΔCAGR 平均相差 **1.86pp**、最大 **7.86pp**（折 11：−6.17 vs +1.70pp），Pearson r = **0.739**，符号仅 **12/18** 折一致（13/18 若把折 9 的 0.00/0.00 记为一致；其余 6 折里折 5 一方为 0.00）⇒ 6.0→8.0 **改写了折结果**，「近似空操作」的读法不成立。
- 两臂真正的缺陷：

  > `atr_6_0` 与 `atr_8_0` 的均值增益只有 +0.30pp / +0.14pp，且**各自删掉单折即翻负**（`atr_6_0` 删 {15} → −0.08；`atr_8_0` 删 {13} → −0.02，另有 {5}/{14}/{15} 三折同样能翻）⇒ 这两臂是**一折宽的噪声**，对单调性没有信息量。至于 `clip(·, 3.5, 7.5)` 是否把 8.0 压到 7.5：**无法判定**——本网格没有 `atr_7_5` 臂，未测即不得断言；而两臂逐折 ΔCAGR 平均相差 1.86pp、符号仅 12/18 一致，也不支持「近似空操作」的读法。

- **只有 `atr_none`（`stop_mode="none"`）完全跳出自适应乘数**，是 Grid A 中唯一真正改变止损行为的臂。
- **对假设 A 的处置**：因此"A 被证伪"这句话的严格范围是"**在自适应乘数带内放宽 / 在字面意义上关闭**均无益"，**不等于**"任何放宽都无益"。要真正测"更紧 / 更松"，必须换 `{3.5, 4.0, 4.5}` 并配 `blend_enable_adaptive_stop_atr=false`（`cdhb` 报告 §4.1 的附带建议，**本轮未执行**）。

### 5.4 LOO（留一折）在本批是**伪检验**，不得作为稳健性证据

- **算术事实**：去掉单折后的均值 = (18·m − d_i)/17，只有当 **|d_i| > 18·m** 时才可能翻转符号。本批所有"均值为正"的臂都满足 `max|d_i| < 18·m`：`cdhb/008_4` 38.09 < 89.01、`crb/008_4` 47.85 < 69.28、`cfsb/010_5` 40.19 < 103.43、`cfsb/atr_none` 18.97 < 61.04 ⇒ **"18/18 次 LOO 全为正"是构造上必然，不是证据**。
- **分散度反而证明它是伪检验**：单折 |ΔCAGR| 就超过全样本均值的折数 —— `cdhb/008_4` **11/18**、`crb/008_4` **12/18**（`attribution.txt`）。**一折的摆动比整个"增益"还大**，LOO 却恒正，恰好说明它的判据选错了对象。
- 对照口径：`cdhb` 的 LOO 区间 +2.9955 ~ +6.2306pp、`crb` +1.2607 ~ +6.0351pp（`report.txt`），看起来"稳"，实为上述恒等式。
- ⇒ 本文件**不采用** LOO 作为任何结论的依据；判据一律用 §5.1/§5.2 的 **k-fold removal**。

## 7. 陷阱清单（引用本批任何数字前必须过一遍）

**(a) 臂文件内部的 `baseline_cagr` / `baseline_sharpe_ratio` / `baseline_max_drawdown` 不是策略基线。**

- 它们是**冻结的 `000300.SH` 等权基准序列**（`comparison_report.json`：`baseline_symbol = 000300.SH`、`baseline_template = equal_weight`、`baseline_params.rebalance_freq_days = 5`、`mean_baseline_cagr = 0.06016900475744777`）。实测：`08_ablate_wf` 的 39 个叶 + 本批 18 个 run = **57 个 leaf × 18 折，`baseline_cagr` 只有 1 条不同序列**（折 1–3 = −49.58% / +14.13% / −36.34%）。
- 它与 `08_ablate_wf/baseline/<strategy>/` 的逐折 `cagr` 相差**逐折最大 147.52pp（`cdhb`）/ 192.13pp（`cfsb`）/ 162.26pp（`crb`）**，均值层面相差 **19.61 / 24.13 / 21.86pp**（冻结列均值 6.0169% vs 策略基线 25.6274% / 30.1513% / 27.8800%）。
- ⇒ **所有 Δ 一律对 `08_ablate_wf/baseline/<strategy>/walkforward_summary.json` 计算**，用臂内 `baseline_*` 会得到完全不同的数（`extra.py` 口径下 `|cagr − baseline_cagr|` 的逐折最大值在 18 臂上落在 114.60–208.83pp）。

**(b) DSR 在本网格饱和，禁止作裁决。**

- walkforward 分支 `n_trials = n_valid_folds = 18`（`backtester/run_backtest.py:1786`），`sr₀ = expected_max_sharpe(18, fold_sharpe_std)` 落在 **3.45–4.32**（逐臂见三分策略报告：`cfsb` §7、`crb`/`cdhb` §6），而全部 18 臂的 `mean_sharpe_ratio` 只有 **1.3958–1.7626** ⇒ DSR 全部压在 `1.1e-56 ~ 1.1e-21`，**数值大小只反映 `fold_sharpe_std` 的第三位小数**，与策略好坏无关。本批任何排序都不使用 DSR。

**(c) 折级 MaxDD 是 63-bar 折内均值，不是全路径回撤。**

- `mean_max_drawdown` 4.15%–5.41% 是 18 个 63-bar 折内回撤的算术平均；同窗口 standard 整段（1,161 bar）`cdhb` 实测 **11.8066%**。两者**不可相减、不可互相校验**。折内 MaxDD 的折间标准差约 2.08pp（`cfsb` 基线逐折 1.67%–8.53%），这也是 ΔMaxDD 的比较基准 —— 本批所有 ΔMaxDD 都 ≤ 1.03pp（`crb/010_5`），即**全部小于半个折间标准差**。

**(d) `0.015` vs `0%` 现金计息不可混比**：本批 18/18 为 `--cash-sweep-rate 0.015`（manifest 数值实证），`03_r2b_oos` 为 0%，任何跨组并列都无效。

**(e) `--strategy-params` 必须用策略前缀键**：`resolve_param` 的解析链是 `{pfx}_{name}` → `alt_prefix` → `blend_{name}` → 裸 `p[name]` → `getattr(cfg, name)`（`blend_base.py:214`）。写裸名会泄漏全局 `StrategyConfig`（`wq_alpha_id=101` 事故的确切机制）。

## 9. 与 `L2.49`（换手率削减）的关系：本批**不构成**其落地依据

1. **本批确实测出"换手可降、短期不损收益"**：Σ换手 −28.4% ~ −54.7%、Σrebalances −28.3% ~ −55.3%（9/9 臂全降），且 `cdhb/008_4`、`crb/008_4`、`cfsb/010_5` 的 ΔCAGR 分别为 +4.9450 / +3.8488 / +5.7464pp（**都为正，不是损失**）。
2. **但增益不可归因**：三个正号的 ΔCAGR 分别只需 **3 / 2 / 4** 个折就能翻成负号（§5.2），ΔSharpe 分别只有 +0.0924 / +0.0059 / +0.3297（`crb` 的 +0.0059 ≈ 0）。⇒ 可主张的只有「**收紧不损收益（成本未测出）**」，**不是**「收紧提高收益」。`L2.49` 若要引用，只能引用换手侧的机械量（Σrebalances / Σturnover），**不能**引用收益侧。

   - `L2.49` / `L2.36` 的预注册合格线是**单边稳态 ≤ 8.0×/年**（硬上限 10.0×/年、下界冗余 ≥ 3.0×/年，`docs/development_plan.md` `L2.36` / `L2.49` 行）；`L2.36` 自己的基线读数是**双边 16.3608× / 单边 8.1804×**。

     | 9 | Four-State Risk-Managed（`03`） | 6 | 13.62× | 6.81× |
     | 10 | Four-State Shield（`03`） | 6 | **9.74×** | 4.87× |

     ⇒ **10 个已评分 run 的双边年化 = 9.74 – 15.09×/年（单边 4.87 – 7.55×）**，即简报口述的 **9.7 – 15.1×/年**；**该数已从产物复现，旧的「无法判定」项作废（关闭）**。
   - **本网格自身 18 臂（全部恰为 18 折 × 63 bar）同法复算 = 双边 6.93 – 15.77×/年（单边 3.47 – 7.89×）**，三策略基线 **15.77 / 14.83 / 15.10×**。旧稿的 **7.06 – 16.09×** 是同一批 run 沿用固定 `18×63` 分母的结果（各值系统性高约 2%，即折实际跨 93–99 日、18 折合计 1,707 日 = 4.674 年，而 `18×63/252` 名义上是 4.5 年）。
   - **必须披露的一处口径分裂（两个数都对，但属两个不同总体）**：**9.7–15.1×** 是「10 个已评分 run（4–6 折，含 504-bar 折）」的区间；**6.9–15.8×** 是「本网格 18 臂（18×63）」的区间。旧稿低端 **7.06× 的来源不是折形不符**——它是 `crb inertia_015_10`，本身正是 18×63 的 run，同法复算为 **6.93×**；折形不符真正会出事的是上面那句 `01_r1_longwin` 的 85–117×。两个区间不可互相替代：对 `L2.49` 的换手对比一律引用**已评分 run 的 9.7–15.1×**。
   - **裁定（用户，2026-10-25）：评分上限 = 双边 10.0×/年，即单边 5.0×/年**。这比 `L2.49` 预注册的单边 8.0×/年 合格线**收紧 37.5%**（5.0 / 8.0 = 0.625）。这是一次**授权收紧**——做法是把 `docs/development_plan.md` 的 `L2.49` 行按新上限修订，**不是**一处需要"调和"的口径不一致。
   - 按该上限的实际后果（直接读上表）：本网格 18 臂中只有 `inertia_010_5`（8.90 / 7.61 / 8.89×）与 `inertia_015_10`（7.15 / 7.04 / 6.93×）**六格在限内**，9 个 ATR 臂（12.95–14.97×）与三策略基线（14.83–15.77×）**全部超线**；10 个已评分 run 中只有 Four-State Shield（`03`）的 9.74× 在限内。
4. **因此**：`L2.49` 的落地依据**不能**来自本批的收益侧数字；能提供的是(a) 一条机械可验的换手弹性曲线（0.05/2 → 0.15/10 的 Σrebalances 与 Σ换手），(b) 一个必须写进口径说明的反例（`0.15/10` 三策略全拒、`crb` 0.10/5 悬崖 −4.13pp / ΔSharpe −0.3223），以及 (c) 口径已定：**双边口径 + 双边 10.0×/年上限（= 单边 5.0×）**，`L2.49` 行按此修订；本批与之的对比直接引 §9 第 3 条的 9.7–15.1×，不再有"待裁决"项。
