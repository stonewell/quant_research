## 1. 结论（先给裁定，再给证据）

**NO-GO。** 建议把 `L2.49` 按**负结果**结案（`[x]`），不再以「找到换手杠杆」为交付目标，且**禁止**重提冷却 / 再入门槛 / 往返预算（`L2.36` + §4.18 第 3 项双重封口）。

三条互不依赖的理由，任一条单独成立即可结案：

| # | 理由 | 数字 |
| :-- | :--- | :--- |
| 1 | **换手结构已经解释完**：出场清仓是最大单一来源，而「信号 vs 漂移」的拆分说明**执行层不存在可平滑对象** | 出场 **28.35%** = 4.7137×/yr；resize（改仓）只占 **29.83%**，其中漂移成分仅 **3.19%** = **0.5308×/yr**；信号占 resize 的 **90.33%** |
| 2 | **唯一有足够射程的杠杆族已被实测否掉**（不是估计） | 要把 16.63× 压到 8.0× 需抑制 **51.9%** 毛额 ⇒ 阈值 ≈ **0.110**（0.05 的 2.2 倍）；`09_param_grid` 实测 `0.10/5` → **8.47×**，但 crb **−4.13pp**、`0.15/10` 三策略全拒（cdhb −3.45 / cfsb −1.27 / crb −5.81pp） |
| 3 | **摩擦预算本身小于噪声地板一个量级** —— 这正是「净收益检验」永远不可能通过的原因 | 全摩擦 **201.1 bp/yr**；削减到合格线 8.0× 的最大节省 **104.4 bp/yr**；18 折 2-SE 门槛 **1,947 / 2,809 / 2,225 bp**（均值 2,327）⇒ 最大节省 = 门槛的 **4.5%**，**全部摩擦归零**也只是 **8.6%** |

**最强的一个数**：**把摩擦削到零，也只能拿回 201.1 bp/年 = 2.01pp 的 CAGR，而这只有 18 折 2-SE 检测门槛（2,327 bp）的 8.6%** —— 即便 8.0× 合格线「完美达成」也只值 104.4 bp（4.5% 门槛），**远小于** `L2.49` 第 5 条 (d) 预注册的噪声下限，因此任何削减方案的收益在现有 walkforward 形态下**结构上不可判定**；而唯一能触及门槛的杠杆族（加宽 per-asset 带宽 / 粗粒度合并）的**实测代价是 1.3–5.8pp 的 CAGR**，是它所能节省成本的 **1.3–6.6 倍**。这不是「还没找到好杠杆」，是**收益侧分母太小**。

**一句话**：换手 16.63×/yr 是真的、可解释的、也是贵 2% 的；但**它不是这个策略的收益瓶颈**，`L2.51` 那条 10.0× 硬闸门的正确用法是**当评级筛子**（降 A→B），不是**当优化目标**。

### 2.2 预注册门槛（沿用，不改）

- 合格线：**双边 ≤ 8.0×/年**（单边 4.0×）
- 硬上限：**双边 10.0×/年**（`L2.51`，`run_audit.py::TURNOVER_CEILING_ANN = 10.0`）
- 可检测下限：沿用 `L2.49` 第 5 条 (d) 仓内纪律的 2-SE 读数（见 §11）

### 2.3 三条方法论纪律（全部踩过坑，写死）

1. **不按 `action` 分类，按 (prior_weight, target_weight) 状态分类。** 3,633 条 `SELL` 里有 1,524 条只是**减仓**、并未清仓；按 `action` 分会把 trim 记成 exit。本文六个桶：`1_init_entry`（折内首次建仓）/ `2_reentry`（同折同标的前有过清仓后的再入场）/ `3_fresh_entry`（其余建仓）/ `4_exit`（清到 0）/ `5_trim`（减仓）/ `6_add`（加仓）。
2. **信号/漂移拆分用恒等式，不靠猜。** 对每个 (fold, batch, symbol) 取**上一行 CSV 的 `target_weight`** 作 `T_prev`：
   `signal_w = target_weight − T_prev`，`drift_w = T_prev − prior_weight`，并断言 `signal_w + drift_w == weight_change`（实测最大残差 `2.2e-16`）。含义：`signal_w` 是「今天的目标相较于**上一次我们要求的目标**变了多少」＝策略决定；`drift_w` 是「上一次的目标相较于**实际持仓权重**差多少」＝价格自己走出来的偏离。
3. **`fold` 不是主键，`batch` 必须在每个分组键里。** `batch 2` 的 `fold` 从 1 重新开始，首版漏掉 `batch` 导致折数被从 108 错算成 54 —— 已在 `decompose_turnover.py` 的分组键中修正，本文所有数字均为修正后。

### 2.4 年化口径

年化一律走 `run_audit.turnover_annualised_from_folds` 的既有口径：**逐折** `total_turnover / ((end−start).days / 365.25)`，再对 108 折**取均值**（不取 Σ/Σyears，那会把折长混进度量）。

> ⚠️ **一处早期纯 artefact，已修并披露**：首版用「该折成交行 `max(date) − min(date)`」做分母，在只有 1–2 笔成交的折上把年化值放大到 **40.85×/yr**（真实 ≈7.45×）。任何换手年化都必须用 `walkforward_report.csv` 的 `start_date`/`end_date`，不能用成交行的日期跨度。

### 4.1 为什么「权重平滑」在这套引擎里没有对象

| 量 | 值 |
| :--- | ---: |
| resize（改仓）行数 / 占毛额 | 1,754 行 / **29.83%** |
| resize 的**中位** `\|signal_w\|` | **0.0784** |
| resize 的**中位** `\|drift_w\|` | **0.00616**（均值 0.00959、p90 0.02151） |
| 中位 `\|drift_w\| / \|signal_w\|` | **7.38%** |
| resize 中 `\|Δw\|` 的中位数 | 0.0768（最小值 **0.05001**） |
| 「漂移 > 0.03 / 0.05」占 resize 毛额 | **5.09%** / **1.08%** |

**机制**：`blend_base.py` **每日重算目标**（没有调仓日历），惯性闸 `_step_asset_inertia` 的带宽门槛判的是**目标变化** `|T − T_prev|`（`common/allocation_templates.py:217-340`，`sell_thresh = thresh_t × ratio`），而 `min_weight_change` 部署值 0.05 ⇒ **改写行的 `|Δw|` 下界被钉在 0.05**（实测最小 0.0500103，`|Δw|<0.05` 的 630 行**全部是建仓/清仓**，resize **零行**）。这意味着：
- 漂移**从来不会被单独结算** —— 它被捆在信号里一起过大闸；
- 单个事件的漂移量级本身比信号**小一个量级**（7.4%），且 drift 上界由两次事件之间的价格位移决定；
- 一个「只抵消漂移」的尺寸带，最多只能拿走那 **0.5308×/yr**，**并且**还要求 drift > 带宽（否则不动）—— 而 drift 的 p90 只有 0.0215，**装不进 0.05 的闸**。

⇒ **`L2.49` 第 4 条 (d)「子策略权重平滑」作为降换手杠杆，被本测量以「无对象」否定**（与 `L2.49` 第 13 条独立复现的结论一致：`resize` 在 `|Δw|<0.05` 的桶里全 0 行）。

### 4.2 拆分对判定的直接后果

- **出场（28.35%）不能用权重侧手段削减**：清仓是二元事件，任何「带」都只能推迟它 —— 那正是 `L2.36` 证伪的出场确认，且已被 §4.18 第 3 项扩展为**禁止**。
- **`2_reentry`（12.96%）归 `L2.52`**，已结案「无合资格杠杆」。
- **`1_init_entry`（12.80%）不可削减**：那是折内从空仓建成满仓，任何削减都是「不入场」。
- 剩下的 `5_trim` + `6_add`（29.83%）里 90.33% 是信号 ⇒ **权重再估计侧的真实可削减池 ≈ 0.53×/yr（3.19%）**。

**这就是「还剩多少增量」的直接答案：按权重侧口径，天花板 0.53×/yr（= 6.4 bp/年 = 0.064pp CAGR），不到 2-SE 门槛的 0.3%。**

## 6. 摩擦口径审计（本轮的独立发现，必须先说）

在把「换手」换算成「bp/年」时发现仓内存在**两套相差 2 倍的口径**，且**都不是逐字对齐账本的**：

| 口径 | 公式 | 在 16.6290×/yr 下的值 | 出处 |
| :--- | :--- | ---: | :--- |
| §16.15.13 | **单边**换手 × 12.0817 bp | **100.56 bp/年**（原文 85.26 bp @ 7.0567×） | `docs/version.md:2480` |
| `L2.51` 第 3 条 / `FORENSIC_AUDIT` §6.4 | **双边**换手 × (10–12.5) bp | 166–208 bp/年 | `FORENSIC_AUDIT.md:340` |
| **本轮实测（无口径假设）** | `Σtotal_cost / 平均权益 / 折年数` | **201.15 bp/年** | `friction_rate.py` → `out/friction_rate.json` |
| 换手 × 单位成本（双边读） | 16.6290 × 12.0946 | **201.12 bp/年** | 同上，与实测差 **0.01%** |

**裁定：双边读是对的，`85.26 bp/年` 低了整整一个买腿。**

理由（三条，互相独立）：
1. **维度**：`total_turnover` 对**买卖两侧**都累加 `trade_val`（`allocation_backtester.py:1803` / `:1825` → `:1828`），而 `total_cost / Σtrade_value` 是**每单位成交额**的成本率（实测 **12.0946 bp**：BUY 10.0 / SELL 15.0，`out/friction_rate.json::cost_rate_bp_all`）⇒ 只有「双边 × 该比率」量纲自洽。
2. **账本**：`friction_rate.py` 完全**不经过换手** —— 直接 `Σtotal_cost / 该折平均权益 / 折年数` 再对 108 折取均值 = **201.15 bp/年**，与双边读的 201.12 只差 0.01%；单边读的 100.56 则是账本实际收费的 **50.0%**。
3. **外部锚**：`FORENSIC_AUDIT.md` §6.4 的独立实测「年化摩擦 1.4%–1.9%（2,062–2,893 RMB / 10 万 / 1.5 年）」在 9.74–15.09× 上对应 **12.6–14.4 bp/单位**，与 12.09 同量级、与 6.05 差一倍。

**对既有结论的影响（必须披露，不许悄悄改）**：
- `L2.52` 的「唯一合资格杠杆天花板 = 总摩擦的 **2.1%** ≈ **1.8 bp/年**」：**份额 2.1% 不变**（它是成本结构的比值），但**基数应为实测的 201.15**，故 bp 值应为 **≈4.2 bp/年**。`STAGE1_REPORT.md:353` 已明确写过「85.26 bp/年 来自 §16.15.13，非本轮实测」⇒ 这不是 `L2.52` 的错，是**引用基线的口径错**。
- 本文 **§11 的噪声地板比对**一律用 **201.15 / 201.12 bp**，不用 100.56。
- 该更正**不放宽任何裁定**：分子翻倍后，「节省 / 门槛」从 2.2% 升到 **4.5%**，仍然远小于 1。方向不变，量级不变。
- **§16.15.13 的 85.26 bp/年 本文不改**（不在本行所有权内）；建议由 `docs/version.md` 的维护者在下次触碰该节时按本节三条件更正，并在 `L2.49` 结案记录里留痕。

### 9.1 逐条读法

**(a) 漂移带 → 6.4 bp/年，6.2% 进度。** 天花板就是 §4.1 那个漂移成分本身（0.5308×/yr）。之所以不推荐，不是因为它有害，而是因为**它太小**：6.4 bp/年 = **0.064pp** CAGR = 2-SE 门槛（2,327 bp）的 **0.28%**。而且实现上它要求 drift > 带宽才动作（drift p90 = 0.0215），会引入**未对冲的权重漂移**（偏离目标不纠），这与「跟住目标」的引擎语义相反。

**(b) `asymmetric_sell_ratio` 0.60 → 1.0 = 严格 0，这是本轮最干净的一个负面结果。** 该杠杆的语义是「卖出带宽 = 买入带宽 × ratio」，把它拉到 1.0 只是让**卖侧闸门与买侧一样宽**。实测：**六个策略的 trim 行中，`|Δw| < 0.05` 的成交额全部为 0.0000**（`out/ceilings.json::asymmetric_sell_wiring` 逐策略 `trim_share_absdw_lt_0.05 = 0.0` 六连）。原因与 §4.1 同源：`_step_asset_inertia` **先**用 `thresh_t` 判一次、**再**用 `sell_thresh = thresh_t × ratio` 判一次（`allocation_templates.py:254`），两者取最大 ⇒ 收紧的那侧已经把 `|Δw| < 0.05` 的行全挡在门外，**把 ratio 提到 1.0 一格也擦不掉**。
> 附带事实：该杠杆**只对 `cdhb` 接线**（`blend_base.py:609`，`asymmetric_sells` 默认 True 仅限 `cdhb` 前缀），其余五策略**根本没有这条线**。因此任何「调 asymmetric ratio 降换手」的方案，在 5/6 的策略上连作用对象都不存在。

**(b′) ratio → 1.6 → 3.0 bp/年。** 越过买入带宽之后开始有效（cdhb 的 `|Δw|<0.08` 的 trim 占其换手 **9.54%**），但**它削减的是「减仓的灵敏度」= 把减仓推迟** —— 这正是 `09_param_grid` 已经测过的那条轴（更宽的 `min_weight_change`），且**方向上是加风险**（该减不减）。不推荐。

**(c) 组合级再平衡带 → 结构性退化，不是「小」而是「没有对象」。** 实测：2,877 个调仓日**中位只有 1 笔成交**、**55.26%** 的日期只有 1 笔、**82.27%** ≤2 笔（p90 = 3）。也就是说这个账本**从不「全票同向微调」**；一个作用在「组合净敞口变动」上的带，要么永远不触发，要么把整天的调仓**整体**取消 ⇒ 它**等价于调仓频率杠杆**（已由 `09_param_grid` 的 `min_holding_bars` 轴实测否掉）。数字上它看起来有 12.36% 的毛额（=「`|净敞口变动| < 0.05` 的日期」上的名义额），但那是**由「每天只动一只票」造成的「净额小、毛额大」假象**，不是可切除的 churn。

**(d) 权重平滑彻底无对象** —— 见 §4.1：`|Δw| < 0.05` 的 resize **零行**，最小 resize `|Δw| = 0.0500103`。**平滑一个不存在的对象是本行最容易被误当成「待办」的伪任务**，此处明确注销。

**(e) 成本感知的目标层 → 上界 130.8 bp/年，但两处致命。** 上界来自「resize 路径的全变差超出」（`Σ|s_k| − |Σ s_k|`）：**65.03%** 的 resize 毛额是**自我抵消**的来回（完美前瞻才拿得到）。而**因果可实现版本就是加宽 per-asset 带宽**（因为要做到「今天少动一点、下次再补」，在引擎里只有 `min_weight_change` / `min_holding_bars` 这两个旋钮）—— 那条轴已由 T4 实测否掉。**完美前瞻上界不可写进预注册，因果版本已证伪** ⇒ 不作为候选。

**粗粒度合并（k=2 → 7.24×，k=3 → 5.59×）**是唯一「算术上够」的族，但：
- 它是**一阶估计**（`out/ceilings.json::coarse_grain_ceiling.method` 已写明假设：被跳过的腿由下一次原样补上、合并事件上的持仓等于已实现持仓），**真实粗粒度还会改变持仓，因此这是节省的上界**；
- 它**等价于把带宽拉到 0.10–0.15** —— 也就是 T4 已经实测掉的同一族（**不是新杠杆**）。

**加宽 per-asset 带宽**是**唯一有实测射程**的杠杆：从 16.63× 出发需要抑制 **51.9%** 毛额 ⇒ 按 `|Δw|` 分布内插，阈值需 **≈0.110**（2.2 倍于部署值 0.05；`out/ceilings.json::band_widening_reach`：th=0.10 抑制 46.62%、th=0.15 抑制 73.80%）。`09_param_grid` 的实测 `0.10/5` 落在 **8.47×**，**与内插一致（这验证了内插，不是巧合）**。**但它没过净收益检验** —— 见 T4。

### 12.2 若一定要再跑一个实验（本文**不建议**，但按要求给出可预注册形态）
