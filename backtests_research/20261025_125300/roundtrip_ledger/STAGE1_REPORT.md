**状态**：阶段一（往返取证）已完成。**阶段二（方案搜索/落地）未开工**——受用户裁决与 `L2.48` 双重门控，

## 3. 方法与精确过滤器

### 3.1 配对定义（逐字实现规格第 1 条）

配对键 = (`run`, `strategy`, `fold`, `symbol`)。在键内按 (`date`, `rebalance_id`) 排序后：

* **出场腿**：`target_weight <= 1e-12` 且 `prior_weight > 1e-12`（真正清零，不是部分减仓）；
* **再入腿**：该标的的**下一条**记录满足 `target_weight > 1e-12` 且 `prior_weight <= 1e-12`。

取「下一条」而不是「后面任意一条」，是为了把「中间无持仓」变成**结构性保证**而非假设：
若中间真的还有持仓，它必然留下一条 `prior_weight > tol` 的成交记录，此时判 `no_reentry`
（并计入分母），**不硬配**（单测 `test_reentry_after_intermediate_add_is_anomaly_not_pair` 钉死这一条）。

* `gap_return = price_entry / price_exit − 1`（**正 = 买回更贵 = 这一趟在价格上是亏的**）；
* `bars_elapsed` = 该标的交易日历上的索引差（**bar 数**）；
* `cal_days` = 日历日差（**近似口径**，只在缺少 bar 时用，且明标为近似）；
* `mae`/`mfe` = 放弃持仓区间 `(exit_date, entry_date]` 内 `low/p_exit − 1` 的最小值与 `high/p_exit − 1` 的最大值；
* 摩擦 = 出场腿与再入腿 `total_cost` 之和；`roundtrip_cost_bp` = 该和 / `|exit trade_value|`。

**排除项（如实披露）**：部分减仓（`0 < target_weight < prior_weight`）**不进入**本台账——它们不把仓位清零，
不是「止损出局」。这也是本台账与 `docs/version.md` §16.15.15（用任意卖腿→买回配对，1,026 对）
**定义不同**的原因，两者计数**不可直接相减**。

### 3.2 价格口径已逐值核验（不是假设）

CSV 的 `price` 列**是复权价**，不是原始价：以 `601225.SH` 为例，`price/raw_close` 在
2022-07-14 / 2023-07-21 / 2024-04-11 三个**除权日**各上跳一次，其余日期恒定 —— 即
`price(t) = raw_close(t) × factor(t) × 常数`，是**总收益路径**。因此 CSV 自己算出的 `gap_return`
**不含分红缺口**，跨除权日也成立（这是 §3.1 能只靠 CSV 就成立的前提）。

进一步用本地缓存**逐值核对**（`summary.json → price_calibration`）：把 `ohlcv_bars.close × adjust_factors.factor_hfq`
（按标的、按日 ffill）与 CSV 的 `price` 逐行比：

* 主范围 **7,052 行**可比，**64.28%** 逐值完全一致（相对偏差 < 1e-9）；
* 偏差**只集中在 5 个标的**：`600660.SH`（278 行，最大 1.89%）、`601225.SH`（856 行，0.20%）、
  `601288.SH`（827 行，0.31%）、`601872.SH`（699 行，0.09%）、`601919.SH`（672 行，0.02%）；
* 这 5 个的偏差形态是**除权日台阶**（因子快照差了一次事件），**不是随机噪声**；
* 真正决定结论的**路径级**核对（`gap_calibration`）反而更干净：用缓存路径复算的 gap 与 CSV 的 gap，
  **中位绝对差 0.0（<1e-15）、97.55% 在 1e-4 以内、100% 在 1e-2 以内**（主库层）；
  辅助库层 N=2,867，中位绝对差 **0.0**、98.05% 在 1e-4 以内、98.64% 在 1e-2 以内。

⇒ 结论：**bar 数与 MAE 用的路径与 CSV 同源**，上面的台阶偏差只影响 5 个标的、量级 ≤ 1.9%、
且只出现在跨越该除权日的窗口里；这一点在 §7 记为残余。

### 3.3 去重（必须做，否则 n 与 t 值一起虚高）

同一笔经济往返会**被多次登记**：`01_r1_longwin` 的 4 个 756 天窗口本身互相重叠，
且 **6 个策略共用同一个宇宙**，同一 (`symbol`, `exit_date`, `entry_date`) 会在多个
strategy/run 里各出现一次。实测多重登记倍数：

| run | 池化 / 去重 | 倍数 |
| :--- | ---: | ---: |
| `01_r1_longwin` | 2,184 / 1,029 | **2.12** |
| `03_r2b_oos` | 188 / 130 | 1.45 |
| `07_r3_oos_bear` | 212 / 131 | 1.62 |
| `08_ablate_wf/baseline` | 283 / 209 | 1.35 |

去重规则写死在 `dedup_round_trips()`：以 (`symbol`, `exit_date`, `entry_date`) 为键，
保留 `|exit_trade_value|` 最大的一条作代表。**判据在去重口径上裁决**，池化口径并列报告
（两者结论相同，见 §6）。摩擦/成本类统计**不去重**（那是按 run 计的流量）。

### 3.4 预注册阈值（写死为常量，不接受 CLI 覆盖）

规格第 2 条把「正 gap 占比**高**」「中位 bars **短**」写成形容词。为让判据机械可执行且
**不可能事后调参**，本模块把它们固化为常量（`roundtrip_ledger.py::PREREG`）：

```
H2_POS_SHARE_MIN    = 0.50   # 「占比高」= 过半
H2_WEIGHTED_GAP_MIN = 0.0    # 照抄「加权 gap ≥ 0」
H2_MEDIAN_BARS_MAX  = 6      # 「中位 bars 短」= 不长于机械冷却底
                             #   asset_stop_cooldown_bars(5) + 1 根确认 bar = 6（§16.15.15）
H1_NEG_SHARE_MIN    = 0.50
```

**必须标注**：这 4 个数是**本轮首次测量前**写下的**对定性规则的机械化**（规格未给数字），
不是规格原文；它们不进 CLI、不被结果反向调整。若协调者认为应取别的机械化，**改常量重跑即可**，
测量量本身（§5）不受影响。

## 5. 测量结果

### 5.1 频率与再入率

* 出场事件 **3,881**；被配对 **2,867**（**再入率 73.87%**）；未配对 **1,014**（26.13%）——
  含折末截断与确实没再买回两类，**无法从 CSV 区分**（见 §7）。
* **去重后**每策略每年往返数：`01_r1_longwin` **59.9** / `03_r2b_oos` **13.9** /
  `07_r3_oos_bear` **14.2** / `08_ablate_wf/baseline` **14.9**。
  `01` 的 4 倍偏差**不是**清洗出来的信号差异，而是**折长敏感**：756 天折里再入有机会在折内闭环，
  94 天折里同样的往返会被折界切断（`01` 的成交行密度也高 2.6 倍：493 vs 183–201 行/策略年）。

故只当作**管线正确性自校验**，不作为新证据引用。

### 5.8 消融对照（**事后加入，非预注册**，仅作方向性证据）

`08_ablate_wf` 同一批 18 折、同宇宙，用同一匹配器重跑（`--scope all` 的子集）：

| 臂 | 出场事件 | 去重往返 | 正 gap | gap 加权 | 深亏(≤−5%) 往返 | 深亏正 gap | 深亏 gap 均值 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `baseline` | 630 | 209 | 67.9% | +3.19% | 81 | 81.5% | +5.77% |

| `no_inertia` | 1,003 | 380 | 63.9% | +2.90% | 147 | 72.8% | +4.51% |
| `no_circuit` | 630 | 209 | 67.9% | +3.19% | 81 | 81.5% | +5.77% |

**关掉 ATR 止损通道后，深亏全额出场数不降（81 → 83）、正 gap 占比只降 1.6pp** ⇒
往返现象**不是** ATR 止损单独制造的（硬止损 / 追踪止损 / 熔断 / 子策略 FSM 仍在清仓）。
**注意一**：本轮只消融了一条通道，**不能**据此说「止损无关」——`no_atrstop` 的**折末权益确实变了**
（`chan_four_state_blend` 101,824.9 → **103,691.1**、`chan_dual_hybrid_blend` 101,568.5 → 101,436.6），
说明 ATR 止损通道对**收益**有实质影响，只是**不改变往返的次数与 gap 分布**。

**注意二**：`no_circuit` 与 `baseline` 的**成交键**（`fold`/`date`/`symbol`/`action`）逐行相同，
`total_cost` 只差 3.15 元（0.04%）⇒ 熔断在这 18 折里**几乎未改变任何交易决策**。
本表的统计量只依赖价格与权重，因此两行必然相同——这**不是**「熔断无效」的证据，
只是说明熔断不在本台账的作用域内（与 `L2.50` 的熔断可达性话题同源，本轮不展开）。

## 6. 判据裁决（预注册规则的机械结果）

| H2-a 正 gap 占比高 | **61.01%** | `> 50%` | ✅ |
| H2-b 加权 gap ≥ 0 | **+2.95%** | `≥ 0` | ✅ |
| H2-c 中位 bars 短 | **22** | `≤ 6` | ❌ |

## 7. 不可算 / 不可验证项（明确清单）

1. **真正的指数调整不可做**：本地缓存里 `000300.SH` / `000905.SH` / `000852.SH` / `399006.SZ` 等
   7 个指数**只有 2026-09-22 … 2026-10-27 的 20 根 bar**（provider 各 20 行）。本报告用的
   「等权宇宙代理」是**同一 20 只标的的等权平均收益**，不是任何公开指数，**不得**当成市场基准引用。
2. **`is_stop` 真值不可验证**：`walkforward_rebalances.csv` 不落 `is_stop` / `blocking_reason` /
   `actual_weights`（`backtester/run_backtest.py:476-486` 当场丢弃），故「这一笔是不是止损触发」
   **永远只是代理**（用 `exit_realised_ret ≤ −5%` 打标）。任何「止损 vs 非止损」的严格归因
   在本数据上**不可做**。
3. **未配对的 1,014 条出场（26.1%）不可归因**：无法区分「折末截断」与「确实再也不买回」——
   CSV 没有折内日历，只有成交日。**本报告的分布全部以「被配对」为条件**，不得外推到未配对那批。
   （§16.15.15 对同源问题的表述是「0/138 跨折是匹配器键定义的产物、不是证据」，本轮沿用该纪律。）
4. **持股天数精确值不可算**：CSV 只有成交日，两次成交之间是否一直满仓只能靠「中间无成交记录」推断。
   `bars_elapsed` 已由缓存给出，但 `hold_bars`（建仓到出场的实际持有 bar 数）在缺少逐日持仓的情况下
   仍只是**近似**（本报告未使用该量）。
5. **除权日台阶残余**：`600660.SH` 的复权路径与 CSV 在 278 行上最大差 **1.89%**，
   `601225/601288/601872/601919` 在 0.02%–0.31%。若某个窗口恰好跨过那个除权日，
   该往返的 `mae`/`mfe` 会带上同等量级的偏差。**未做修正**（修正需要事件级因子对齐，属阶段二外的事）。
6. **`01_r1_longwin` 的频率不可与其它 run 比较**（折长截断 + 重叠窗口），理由见 §5.1。
7. **本轮没有跑任何回测**，因此**没有任何** CAGR / MaxDD / 双边年化换手的新数字；
   规格第 4 条的主判据（双边年化换手）本轮**未测**（那是阶段二落地后的事）。
   唯一引用到的稳态摩擦基线 **85.26 bp/年** 来自 `docs/version.md` §16.15.13，**非本轮实测**。

## 8. 阶段二候选杠杆（**仅提案，零代码改动**）

约束（规格第 3 条 + §4.18 第 3 项用户裁决）：**不得**提出「阻断/延迟再入」类机制
（等价于延长冷却 / 抬高再入阈值 / 往返次数上限），**不得**重提 2 根 bar 出场确认（`L2.36` 已证伪）、
**不得**重提加宽止损（18 格 ATR 网格已否）。规格据此把合资格集合收缩为**1 项（③）**。
下面按「可证伪的成本侧判据 × 规模」排序，**并显式列出被否项的理由**，以免下一轮回退：

| # | 候选 | 类型 | 可证伪的成本侧判据 | 实测规模上限 | 另一侧代价 / 风险 | 状态 |
| :-- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | **再入份额阶梯**：被止损清零后的**首次**再入只建 **`target_weight × 0.5`**，次次再平衡恢复正常 | **结构（改每笔规模，不改时点）** | 这些往返的**再入腿摩擦**必须下降；`Σ cost(entry legs of bars≤6 pairs)` = 总额的 **4.26%** ⇒ 半仓可回收 **≈2.1%** | ≤ **2.1%** 的总摩擦（约 **1.8 bp/年**，按 §16.15.13 的 85.26 bp/年 基线折算） | 放弃首次再入的一半暴露；本样本 **57.4%** 的往返窗口内最高点曾 +5%，半仓会把这部分让步一半 | **合资格（唯一）** |
| **2** | **#1 的条件化**：仅当 `price_entry > price_exit`（gap>0，已经买贵了）时打半仓；gap ≤ 0（买回更便宜）时满仓 | 结构（同上） | 同上，但只作用在 gap>0 的 **61.0%** 上；可把 **#1** 的让步限制在「已经证明买贵」的回合 | ≤ **1.3%** 总摩擦 | 引入一个路径依赖开关（用已实现价格做条件），需在阶段二**预注册**成常量，否则就是事后调参 | **合资格（#1 的条件化形式）** |

* **#1 的天花板很小**：即使完美实现，回收的是总摩擦的 **2.1%**（`bars≤6` 子群再入腿 4.26% 的一半），
  对应约 **1.8 bp/年**。这与 §16.15.13 对 2-bar 出场确认算出的 **2.69 / 4.40 bp/年** 是**同一量级**——
  即：**换手引擎的「冷却往返」这一块本来就只占摩擦的几个百分点**，主量级不在这里。

  而不是回退到已被禁止的冷却轴。
* **本轮不提议任何东西**：上表是提案，不是方案；阶段二仍需 `L2.48` 前置 + 用户批准，
